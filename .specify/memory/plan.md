## Summary

Implement a PyTorch-based PU learning research project that reproduces the nnPU paper's experimental comparison of three methods (PN, uPU, nnPU) on MNIST dataset. The project uses a modular architecture enabling easy extension with custom loss functions. Primary challenge: implementing mathematically correct loss functions that match paper specifications while ensuring reproducibility and GPU acceleration on M4 MacBook Pro.

**Key Technical Approach**:
- **Modular Design**: Separate modules for data, models, losses, training, utils
- **Reproducibility**: Comprehensive seed setting for Python, NumPy, PyTorch (CPU/MPS/CUDA)
- **MPS Acceleration**: Auto-detect and use Metal Performance Shaders on Apple Silicon
- **Interactive Viz**: hvPlot + HoloViews + Bokeh (not matplotlib)
- **Testing**: >80% coverage with pytest

## Critical Implementation Details

### Loss Function Math (CRITICAL)
**uPU Loss**:
```python
# Three separate expectations
positive_risk = π * E_P[l(f(x))]           # Positive samples
unlabeled_risk = E_U[l(-f(x))]             # Unlabeled samples
false_positive_risk = π * E_P[l(-f(x))]    # Positive samples with negative loss

# Unbiased estimator (CAN BE NEGATIVE)
loss = positive_risk + unlabeled_risk - false_positive_risk
```

**nnPU Loss**:
```python
# Same as uPU but with non-negative constraint
positive_risk = π * E_P[l(f(x))]
negative_part = E_U[l(-f(x))] - π * E_P[l(-f(x))]

# Non-negative risk estimator
loss = positive_risk + max(0, negative_part)

# ASSERTION: loss >= 0 always
assert loss >= 0, "nnPU loss must be non-negative"
```

### MPS Device Selection
```python
def get_device(prefer_mps=True):
    if prefer_mps and torch.backends.mps.is_available():
        return torch.device("mps")
    elif torch.cuda.is_available():
        return torch.device("cuda")
    else:
        return torch.device("cpu")
```

### Reproducibility
```python
def set_seed(seed):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    if torch.backends.mps.is_available():
        torch.mps.manual_seed(seed)
    if torch.cuda.is_available():
        torch.cuda.manual_seed_all(seed)
        torch.backends.cudnn.deterministic = True
    os.environ["PYTHONHASHSEED"] = str(seed)
```
